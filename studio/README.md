# 影片工作室

在自己电脑上运行的本地网页应用：把原画做成 9:16 电影镜头 → 多镜头转场拼接 → 旁白、环境声、配乐混音 → 导出可直接上传 YouTube Shorts / 小红书的 MP4。

## 启动

需要 Python 3.10+ 和 ffmpeg。

- **Windows**：
  1. 从 python.org 下载「Python install manager」并安装，然后在 PowerShell 运行 `py install 3.14`（不要用刚发布的最新版，依赖库可能还没跟上）
  2. 运行 `winget install Gyan.FFmpeg`，装完关掉窗口
  3. 双击 `START-Windows.bat`
- **macOS / Linux**：运行 `./start-mac.sh`（没有 ffmpeg 的话先 `brew install ffmpeg`）

首次运行会自动安装依赖，然后浏览器打开 http://127.0.0.1:8765 。项目文件保存在 `projects/main/`。

## 使用流程

1. **镜头**：上传原画，在图上点选「起始画面 / 结束画面 / 地平线 / 天光」，调整时长、转场、结尾停顿和各项特效，点「预览关键帧」看效果。
2. **旁白**：每句可以设置开始时间，**可以跨镜头**（声音先行或延后）；时间线上超出片尾的会标红。
3. **配乐**（可选）：上传音乐，旁白出现时自动压低音乐音量。
4. **渲染成片**：输出到 `projects/main/out/`，页面里可以直接预览和下载。

## 配音

每句旁白有两种来源：

| 方式 | 你需要提供 | 说明 |
|---|---|---|
| 生成配音（默认） | 不需要提供任何东西，电脑能联网即可 | 微软 Edge 神经网络语音，免费、无需密钥。史诗旁白推荐「云健」，语速 −20%、音调 −8Hz |
| 上传录音 | 一个音频文件（mp3 / wav / m4a） | 你自己录的，或者在剪映、魔音工坊、ElevenLabs 等平台生成后导出的 |

注意：Edge 语音是微软的非官方免费接口，**商用授权不明确**，也可能随时失效。账号要做商业化的话，建议用有明确商用授权的平台生成，再用「上传录音」导入。
